# 城渡船 釣果アナライザ

三重県尾鷲市・三木浦漁港の渡船「城渡船」の釣果データを可視化・分析するブラウザツールです。
[公式サイトの最新釣り情報](https://zekkouchou.com/shirotosen/catch.php) から取得した
**1609件（2186魚種レコード・60魚種）** をもとに、傾向の分析と釣行日の予想を行います。

## 機能

- **ダッシュボード** … 全魚種／サイズ（10cm刻み）／魚種ごと／時間帯／潮汐／潮回り／日別の7軸で集計。
  すべて横棒グラフ。「件数」と「総数（匹数）」を切り替えでき、配色（寒色／暖色）で区別できます。
- **釣果データベース** … 日付・魚種・サイズ・匹数・潮回り・釣り人・コメントを一覧。
  行をタップすると実際の釣果写真が開きます（1571件に写真あり）。
- **釣果予想** … 日付を入れると、期待できる魚種をドーナツグラフで提示。
  潮回り・満干時刻・日出没は確定情報として、天候は予報があれば予報を、
  なければ過去10年の同時期の実績シェアを表示します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | スタイル（スマホ・タブレット対応） |
| `lib.js` | 潮汐・月齢・日出没の計算、レコード整形 |
| `app.js` | グラフ描画、データベース、予想ロジック |
| `data.js` | 釣果データ（自動生成物） |
| `scrape.js` | データ取得スクリプト |

## データの更新

```bash
node scrape.js
```

公式サイトの JSON API を全ページ巡回し、`data.js` を再生成します（Node.js が必要）。

## 注意事項

- 潮回り・満干時刻・日の出入りは**簡易推算**です。実データの潮名との一致率は 82%（1609件で検証）。
  実釣の際は正式な潮汐表をご確認ください。
- 元データには**釣れた時刻とエサの情報が含まれません**。
  そのため時間帯グラフはコメントから推定できた31件のみ、エサ情報は掲載していません。
- 天気は [Open-Meteo](https://open-meteo.com/) を利用しています。
- 釣果データおよび写真の著作権は城渡船／各投稿者に帰属します。本ツールは個人的な分析用途です。
